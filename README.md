# Pi Token Optimizer

A Pi package for the local Token Optimizer integration. This initial package provides the extension entrypoint and development harness; optimizer behavior is added in later releases.

## Development

Requires the Node and Python versions pinned in `mise.toml`.

```sh
npm install
npm run typecheck
npm test
npm run test:python
```
